## 3. 交互设计

### 3.1 Ribbon 直接生成

用户选择一个连续矩形数据区域并点击对应图表按钮，插件立即生成一个图表。直接生成不再接受任何会破坏 Skill 一致性的样式参数。

### 3.2 高级生成窗格

删除或禁用以下冲突选项：

- 图表标题
- 数据标签
- 图例位置或隐藏图例
- 自定义图表尺寸
- 小、中、大尺寸预设

高级窗格继续保留，但只允许选择图表类型和覆盖系列方向（自动、按列、按行）。散点趋势线由“散点图加趋势线”这一图表类型定义，不再作为通用样式开关。

### 3.3 成功与失败反馈

- 成功时不弹出阻塞对话框，Ribbon 命令及时结束。
- 失败时提示具体可操作原因，例如“饼图只能包含一个数值系列”或“第一列必须是数值型 X 轴”。
- Office.js 未知运行时错误对用户显示简洁提示，同时在本地控制台保留错误代码、操作阶段和调试信息；不上传工作簿数据。

## 4. 数据解析与可用性

### 4.1 通用选区

- 仅接受一个连续矩形区域。
- 图表至少需要两行两列。
- 保留空白值，不擅自替换为零。
- 系列名称完整保留，包括括号内的币种、单位和口径。
- 日期、百分比和普通数值保持原始类型与数字格式。
- 错误值或非数值只在会破坏目标图表时阻止生成，并指出问题类型。

### 4.2 自动方向识别

解析器必须同时支持研究底稿常见的两种布局：

- 按列系列：第一行是系列名称，第一列是日期或分类，后续列是数值系列。
- 按行系列：第一行是日期或分类，第一列是指标名称，后续行是数值系列。

若布局明确则自动选择；若两种解释都合理，则默认按列，并允许用户在高级窗格中覆盖方向。

### 4.3 固定回归用例

以下最小选区必须生成两系列普通折线图：

- `A1` 为空，`B1="A"`，`C1="B"`
- `A2:A13` 为 2001-01-01 至 2012-01-01
- `B2:B13` 为 1 至 12
- `C2:C13` 恒为 5
- 实际选区为 `A1:C13`

该用例应解析为：日期分类轴、A 和 B 两个数值系列、无图表标题。

## 5. 图表样式契约

### 5.1 所有图表

- 图表尺寸固定为 16×9 cm。
- 图表区和绘图区为白色，无装饰性外边框。
- 无图表标题、轴标题、数据标签、来源文字或其他解说文字。
- 图例固定置于下方，`overlay=false`，黑色，9pt；西文设置 Arial，中文使用宿主字体回退。
- 图例文本直接使用选区系列名称，不删除括号中的单位。
- 系列颜色按 `#640000`、`#8A2626`、`#3D889A`、`#646C86`、`#BE995D`、`#DD965D` 轮转。
- 不添加 3D、阴影、渐变或主题默认装饰。
- 图表优先放在选区右侧；右侧空间不足时放在下方，且不覆盖源数据。

### 5.2 坐标轴图表

柱形图、条形图、折线图、堆积图和散点图必须：

- 分类轴和数值轴显式可见。
- 刻度标签位于轴旁，主刻度线向外。
- 分类轴位于底部；主数值轴位于左侧。
- 主数值轴交叉方式为自动零点。
- 完全隐藏主网格线和次网格线，不用白色或透明线模拟。
- 日期分类沿用日期语义；百分比数值轴沿用源数据百分比精度。

饼图和分离饼图不访问不存在的坐标轴。

### 5.3 类型专属系列样式

系列格式必须按图表类型分派，禁止用同一个“填充色 + 线条色”函数处理全部系列：

- 柱形图、堆积柱形图、百分比堆积图和条形图：只设置实体填充色；柱体描边显式清除。
- 折线图、带标记折线图和堆积折线图：只设置线条颜色和 1.5pt 线宽；所有系列显式设置平滑线。普通折线不显示标记，带标记折线保留标记。
- 散点趋势图：散点系列和趋势线使用对应系列色；不对线型系列设置实体填充。
- 饼图和分离饼图：按数据点轮转色板；无数据标签。

### 5.4 已确认故障及修复边界

Mac Excel 诊断日志已确认当前折线图失败路径：

1. 插件创建折线图。
2. 当前通用系列上色函数访问 `ChartSeriesFormat.fill`。
3. `ChartFill.setSolidColor` 返回 `0xA7120001`。
4. 插件回滚并删除新图表。

修正必须从类型专属系列样式边界解决；不得通过吞掉异常、保留半成品图表或关闭回滚来规避。

## 6. 表格样式契约

### 6.1 格式化表格

- 第一行强制作为表头。
- 表头填充 `#8A2626`，白字、加粗、8pt。
- 数据区白底、黑字、不加粗、8pt。
- 整个选区无任何单元格边框。
- 全部单元格左对齐、垂直居中、允许换行。
- 行高统一为 16pt。
- 关闭当前工作表网格线。
- 在不截断关键文本的前提下限制异常宽列。
- 保留值、公式、数字格式、合并和条件格式。
- 不自动添加斑马纹，也不转换为 Excel 结构化 Table 对象。

### 6.2 斑马纹

- 斑马纹继续作为独立按钮。
- 自动识别并跳过表头；第一行数据使用 `#F5F5F5`，下一行白色，依次交替。
- 若选区没有表头，则选区第一行即使用 `#F5F5F5`。
- 不改变字体、边框、对齐、值、公式或数字格式。
- 可单独使用，也可在“格式化表格”之后使用。

## 7. 实现边界

### 7.1 模块职责

- `SelectionParser`：验证矩形选区，识别表头、分类、方向和系列。
- `ChartPlanner`：把解析结果和图表类型转换为确定的图表计划；不携带标题、标签、图例位置或尺寸覆盖。
- `CiccChartStyle`：输出固定 Skill 样式常量和类型专属系列策略。
- `ExcelGateway`：按计划创建原生图表，分阶段同步并应用类型专属样式。
- `TablePlanner`：输出固定表格计划及独立斑马纹计划。
- `UserFeedback`：把验证错误、能力错误和运行时错误转换为可操作提示。

### 7.2 事务与回滚

- 先读选区并完整验证，再创建图表。
- 图表创建和关键样式写入分阶段同步，以便定位失败阶段。
- 任一关键阶段失败时删除本次新图表，并保留原工作簿数据和已有图表。
- 回滚失败时同时报告原始错误和回滚错误，不覆盖根因。
- 表格格式化在写入前完成选区验证；不得修改单元格内容。
