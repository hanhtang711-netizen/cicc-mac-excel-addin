# 中金 Mac Excel 图表与表格插件设计规格

日期：2026-08-04
状态：已被 `2026-08-04-cicc-skill-parity-usability-design.md` 中与样式、交互和验收有关的规则取代；未冲突的范围与部署背景继续有效

## 1. 项目目标

为 Microsoft Excel for Mac 开发一套中金风格加载项。用户选中连续数据区域后，可通过 Excel Ribbon 直接生成原生图表，或对选区执行标准表格格式化和斑马纹处理。

插件仅复刻原 Windows 插件中与当前工作流有关的功能，不移植其登录、数据服务、模型管理、上传、版本检查、自定义函数、Word 或 PowerPoint 功能。

目标运行环境为用户当前安装的 Microsoft Excel for Mac 16.111.2。实现采用 Office.js Excel 加载项，通过固定 HTTPS 地址加载界面代码；工作簿数据只在本地 Excel JavaScript API 上下文中处理，不发送至插件服务器。

## 2. 已确认范围

### 2.1 图表生成

首版提供以下十种基于当前选区的 Excel 原生图表：

1. 普通柱形图
2. 堆积柱形图
3. 普通折线图
4. 带标记折线图
5. 饼图
6. 条形图
7. 散点图加趋势线
8. 分离饼图
9. 百分比堆积图
10. 堆积折线图

原插件中的组织结构图不属于基于表格选区生成的标准 Excel 图表，且 Office.js 没有对应的原生图表类型，因此不在首版范围内。

### 2.2 表格处理

表格功能仅保留两个互相独立、可以组合使用的按钮：

- 格式化表格
- 斑马纹

原插件中其余子区块底色、强调色、浅色背景和清除表格样式等命令不纳入本项目。

### 2.3 明确排除

- 图表格式化现有图表
- 登录、账户和权限系统
- 外部数据查询、债券数据和自定义函数
- 文件上传、Model 版本和 Model 对比
- 版本检查与自动更新
- Word、PowerPoint 和 PDF 功能
- Windows VSTO、COM、Excel-DNA 或 XLL 兼容层
- Office.js 无法稳定支持的组织结构图

## 3. 技术方案

### 3.1 方案选择

采用 Office.js Excel 加载项，不采用 `.xlam/VBA`。选择依据如下：

- 用户已明确排除 Mac 原生 `.xlam/VBA` 路线。
- Office.js 支持 Mac 和 Windows Excel 中的自定义 Ribbon 命令。
- 无需启用宏，可避免宏信任、隔离属性和加载项自动加载问题。
- 图表与表格操作直接调用 Excel JavaScript API，产物仍为原生 Excel 对象。
- 插件前端可部署为静态 HTTPS 资源，便于后续维护和更新。

Office.js 无法可靠地在同一单元格内分别指定中文和西文字体。字体仅按可用 API 做基础设置，不作为首版验收中的阻断条件；图表结构、选区解析和样式处理是首要目标。

### 3.2 逻辑模块

插件分为以下边界清晰的模块：

1. `SelectionParser`
   - 读取当前 Excel 选区。
   - 验证选区是否连续且达到最小尺寸。
   - 识别表头、分类轴、系列名称、数据方向与数值类型。
   - 为散点图、饼图等特殊类型执行额外校验。

2. `ChartFactory`
   - 将用户选择的图表命令映射到 Excel 图表类型。
   - 基于解析后的选区创建图表和数据系列。
   - 处理趋势线、分离饼图、堆积与百分比堆积等类型专属设置。

3. `ChartStyler`
   - 应用中金系列色、背景、边框、网格线、图例、标题和字号。
   - 处理图表尺寸与放置位置。
   - 根据源数据数字格式为日期轴、百分比轴和普通数值轴选择确定的格式代码。

4. `TableFormatter`
   - 执行标准表格格式化。
   - 独立执行斑马纹格式化。
   - 保证不改变选区的值、公式和数字格式。

5. `AdvancedChartPane`
   - 提供高级生成设置。
   - 只负责收集参数，将标准化配置传给 `ChartFactory` 和 `ChartStyler`。

6. `UserFeedback`
   - 将无效选区、类型不匹配和 API 错误转化为简洁、可操作的提示。
   - 确保 Office 命令无论成功或失败都能正确结束，避免 Ribbon 按钮卡死。

## 4. Ribbon 与交互设计

Excel 中新增 `中金工具` Ribbon 页签，包含两个功能组。

### 4.1 生成图表

提供十个直接生成命令和一个“高级生成”入口。直接点击某一图表类型时，插件使用默认参数立即处理当前选区；高级生成打开任务窗格，允许用户调整参数后再生成。

高级生成设置包括：

- 图表类型
- 图表标题
- 小、中、大尺寸
- 自定义宽度和高度
- 图例位置：上、下、左、右
- 按行或按列生成系列
- 是否显示数据标签
- 散点图是否添加趋势线

### 4.2 表格

提供两个按钮：

- `格式化表格`
- `斑马纹`

两者不自动绑定。格式化表格不会自动添加斑马纹；用户需要时可另行点击斑马纹按钮。

## 5. 选区解析规则

### 5.1 通用规则

- 仅接受单个连续矩形选区。
- 图表选区默认至少需要两行两列。
- 默认把第一行识别为系列名称，把第一列识别为分类、日期或 X 值。
- 若首行符合独立标题行规则，则从选区中排除该标题行，再把下一行识别为系列名称。
- 第一行主要为文本且后续行主要为数值时，判定第一行为表头。
- 第一列主要为日期或文本且其余列主要为数值时，判定第一列为横轴标签。
- 无法可靠识别表头时，使用 Excel 默认系列名称，不从任意数据单元格猜测标题。
- 空白值保留为空白，不擅自替换为零。
- 错误值或非数值内容仅在其会破坏目标图表时阻止生成，并指出问题位置。

### 5.2 按行或按列

默认按列生成系列。高级生成允许显式切换为按行生成系列。显式设置优先于自动判断。

### 5.3 特殊图表

- 饼图和分离饼图只接受一个数值系列；多系列选区会提示用户缩小选区或在高级设置中指定系列。
- 散点图要求第一数值列为 X 值，后续数值列分别作为 Y 系列。
- 散点趋势图默认给每个 Y 系列添加线性趋势线；高级设置可以关闭。
- 百分比堆积图使用 Excel 原生百分比堆积类型，不预先改写源数据。
- 分离饼图使用 Excel 原生 `pieExploded` 图表类型。插件初始化时检查所需 Excel API；若宿主版本不支持该类型，则禁用该命令并提示升级 Excel，不用普通饼图冒充。

## 6. 图表生成与样式规则

### 6.1 默认生成行为

- 每次命令生成一个可编辑的 Excel 原生图表。
- 图表优先放置在选区右侧，并保留空白间距；右侧空间不足时放在选区下方。
- 图例默认位于下方。
- 若选区首行只有一个非空文本单元格，则把该行识别为独立标题行，并把其文本用作图表标题；其他情况不自动填写标题。
- 默认不显示数据标签；饼图可按 Excel 图表可读性规则显示分类名或百分比，高级设置可覆盖。
- 尺寸预设为：小 9×5.5cm、中 11.5×6.7cm、大 15×8.7cm；自定义尺寸接受正数厘米并换算为 Office.js 使用的点值。

### 6.2 中金图表色板

数据系列依次使用：

1. `#640000`
2. `#8A2626`
3. `#3D889A`
4. `#646C86`
5. `#BE995D`
6. `#DD965D`

超过六个系列时从第一种颜色开始循环，并提示用户系列数量已超过基础色板。提示不阻止图表生成。

### 6.3 通用视觉样式

- 图表区和绘图区使用白色背景。
- 不显示装饰性外边框。
- 主网格线使用浅灰色细线，仅在对应图表类型需要时显示。
- 图表文字目标字号为 8pt。
- 中文字体尽力设置为“黑体”，西文尽力设置为 Arial；受 Office.js 限制时允许使用 Excel/macOS 的字体回退。
- 图例、坐标轴和标题保持简洁，不添加 3D、阴影、渐变等效果。
- 日期轴读取第一列的日期格式；无法直接复用时使用 `yyyy-mm-dd`。
- 若首个数值系列的源格式包含 `%`，数值轴沿用相同的小数位数并使用 `0%`、`0.0%` 或 `0.00%`。
- 其他数值轴复用首个数值系列的兼容数字格式；无法复用时由 Excel 自动选择通用格式。

### 6.4 类型专属规则

- 折线图：普通折线不强制显示标记；带标记折线为每个系列显示标记。
- 柱形图和条形图：系列间距使用统一默认值，避免柱体过密或过窄。
- 堆积图：保持系列顺序与源数据顺序一致。
- 饼图：同一饼图内的数据点按中金色板依次着色。
- 散点图：不把 X 值当作分类文本；趋势线使用与对应系列一致或相近的颜色。

## 7. 表格格式化规则

### 7.1 格式化表格

对当前连续选区执行以下操作：

- 第一行作为表头。
- 表头填充 `#8A2626`，文字为白色并加粗。
- 表头字号为 10.5pt，并使用居中对齐。
- 数据区统一为白色背景，不自动应用斑马纹。
- 覆盖选区原有的直接字体、填充、边框和对齐设置，使标准表格结果一致。
- 表格内容目标字号为 10.5pt；超长内容可降至 9pt，但首版不主动缩小整个数据区。
- 文本默认左对齐，数值默认右对齐，日期默认居中。
- 使用细而克制的结构边框，避免给每个单元格添加厚重框线。
- 在合理上限内自动调整列宽和行高，避免长文本使表格过宽。
- 保留单元格值、公式、数字格式、合并状态和条件格式。
- 不将普通区域强制转换为 Excel 结构化 Table 对象。

### 7.2 斑马纹

对当前连续选区执行以下操作：

- 数据行使用白色与 `#F5F5F5` 隔行交替。
- 若选区第一行呈现表头特征，第一行不参与交替。
- 不覆盖已有红色表头。
- 不改变字体、值、公式、数字格式、边框或对齐设置。
- 可单独用于已有表格，也可在“格式化表格”之后执行。

## 8. 错误处理

以下情况不执行破坏性或部分完成的操作，并向用户说明如何修正：

- 未选择有效区域。
- 选区为不连续区域。
- 图表选区小于两行两列。
- 选区包含整行、整列或整张工作表，规模明显不合理。
- 饼图包含多个数值系列。
- 散点图缺少数值型 X 列或 Y 列。
- 图表类型在当前 Excel API requirement set 中不可用。
- 工作表受保护，导致图表或格式无法写入。
- Excel JavaScript API 返回运行时异常。

图表生成采用先验证、后创建、再样式化的顺序。若创建后样式化失败，应删除本次未完成的图表或恢复到可识别状态，避免留下半成品对象。表格处理应先完成选区验证，再批量写入格式。

## 9. 部署、安装与隐私

### 9.1 部署形态

- 插件前端构建为静态 HTTPS 资源。
- 提供 Excel 加载项 manifest 文件。
- 开发环境使用本地 HTTPS 服务；生产环境使用固定 HTTPS 地址。
- 生产部署目标必须支持稳定 URL、TLS 和静态资源缓存失效控制。

### 9.2 Mac 安装

- 用户首次在 Excel for Mac 中旁加载或安装 manifest。
- 安装成功后，`中金工具` 页签出现在 Ribbon。
- 不要求启用 VBA 宏。
- 提供面向非开发人员的简短安装和卸载说明。

### 9.3 数据与隐私

- HTTPS 站点只提供插件代码和静态资源。
- 工作簿内容、选区数据、图表数据和公式不上传至服务器。
- 首版不包含用户账户、遥测或分析 SDK。
- 首版不请求与图表和格式化无关的权限。

## 10. 测试策略

### 10.1 自动测试

- `SelectionParser`：表头、日期轴、文本分类、数值系列、空值、横向数据和无效选区。
- `ChartFactory`：十种图表命令到 Excel 图表类型和配置的映射。
- `ChartStyler`：色板循环、图例位置、尺寸、标题、网格线和字体参数。
- `TableFormatter`：标准表格与斑马纹互不绑定，且不改变值、公式和数字格式。
- 错误映射：常见 Office.js 异常转为可操作提示。

### 10.3 验收标准

- 插件可在目标 Mac Excel 中完成首次安装，并在重新启动 Excel 后继续显示。
- 用户选中有效数据并点击图表类型后，可生成对应的原生 Excel 图表。
- 图表数据引用正确，系列名称、分类轴和数值方向不发生错位。
- 图表应用约定的中金色板和基础视觉样式。
- 高级设置可以控制标题、尺寸、图例、系列方向、数据标签和趋势线。
- “格式化表格”生成红色表头和白色数据区，不自动添加斑马纹。
- “斑马纹”独立应用白色与 `#F5F5F5` 交替背景，不覆盖红色表头。
- 两种表格功能均不改变值、公式和数字格式。
- 无效输入得到明确提示，不留下错误图表或半完成格式。
- 插件运行过程中不上传工作簿数据。

## 11. 后续实现边界

实现计划必须保持本规格范围，不在首版顺带增加组织结构图、现有图表格式化、自动登录、数据服务、遥测或其他表格样式。任何范围扩展需要先修改本规格并获得用户确认。
