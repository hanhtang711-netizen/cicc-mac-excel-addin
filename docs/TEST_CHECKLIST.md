## 合成 fixture 与数据映射

- [ ] 日期 + 单系列：日期为分类/X、数值为唯一系列。
- [ ] 日期 + 多系列：系列名称、分类地址和值地址无错位。
- [ ] 文本分类：文本仅作为分类，不被误判为散点 X。
- [ ] 百分比：数值轴保留 `0%`/`0.0%`/`0.00%` 语义。
- [ ] 负数：负值保留，图表可原生编辑。
- [ ] 空值：空单元格不被改写，其他点仍映射正确。
- [ ] 八系列：前六色顺序固定，第七/八色循环，并显示 palette reuse warning。
- [ ] 独立标题行：自动识别标题且数据起始行正确；手动标题可覆盖。
- [ ] 横向布局：按行后分类和每个系列地址正确。
- [ ] 非法散点 X：给出明确错误且没有创建图表。

## 错误处理与回滚

- [ ] 选区过小、矩阵形状不一致、整行、整列、整表、非连续选区均显示可操作错误。
- [ ] 饼图多系列、散点文本/错误 X、散点非数值 Y 均在写入前失败。
- [ ] 缺少 ExcelApi 1.9 或相关 capability 时显示不支持，不读取/写入选区。
- [ ] 图表创建或样式应用失败时，本次图表被删除，不留下半成品；源单元格未改变。
- [ ] 表格应用失败时不留下半完成格式，用户可安全重试。
- [ ] 所有错误均不输出工作簿内容到控制台、服务器或 telemetry。
